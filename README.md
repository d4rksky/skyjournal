# SkyJournal

ژورنال معاملاتی برای دسکتاپ. معامله را سریع ثبت می‌کنید، عملکرد حساب را می‌بینید، و همهٔ داده‌ها روی همین کامپیوتر می‌مانند.

**SkyJournal** is an offline desktop trading journal. Log trades, review account performance, and keep your data on your own machine.

## این برنامه چیست؟

SkyJournal برای کسی است که بعد از هر معامله می‌خواهد بداند چه کرده، چرا، و نتیجه‌اش چه بوده — بدون فرم طولانی، بدون حساب کاربری، و بدون نیاز به اینترنت.

هر معامله داخل یک **حساب** ثبت می‌شود. شکل فرم را **استراتژی** تعیین می‌کند: فیلدهای آماده (نماد، خرید یا فروش، تاریخ، ریسک، ریوارد، نتیجه و توضیح) از قبل وجود دارند و می‌توانید فیلد دلخواه خودتان را هم اضافه کنید.

## امکانات

- چند حساب معاملاتی، با موجودی شروع، موجودی جاری و هدف درصدی اختیاری
- استراتژی با فیلدهای قابل تنظیم؛ فرم هر معامله کوتاه و متناسب با همان استراتژی است
- ثبت، ویرایش و حذف معامله، همراه با تصویر چارت (انتخاب فایل یا کشیدن و رها کردن)
- جدول معاملات با فیلتر و مرتب‌سازی
- گزارش حساب: سود و ضرر، درصد برد، دراودان، رشتهٔ برد و باخت، و نمودار موجودی
- خروجی CSV: قالب تاریخچهٔ متاتریدر، یا ستون‌هایی که خودتان انتخاب می‌کنید
- ورود گروهی از روی پوشهٔ عکس چارت‌ها
- پشتیبان‌گیری و بازیابی در فایل `.skyjournal` (ادغام با داده‌های فعلی، یا جایگزینی کامل)
- ظاهر روشن و تیره
- کار کاملاً آفلاین؛ برای استفاده به حساب یا سرور نیاز نیست

## چه چیزهایی در این نسخه نیست

اتصال به بروکر یا صرافی، معاملهٔ خودکار، همگام‌سازی ابری، و نسخهٔ موبایل در این برنامه وجود ندارد. SkyJournal دفتر ثبت معامله است، نه پلتفرم معامله.

## پیش‌نیاز

- [Node.js](https://nodejs.org/) نسخهٔ ۲۰ یا جدیدتر
- npm (همراه Node.js نصب می‌شود)
- ویندوز، macOS یا لینوکس

## اجرا

```bash
git clone https://github.com/d4rksky/skyjournal.git
cd skyjournal
npm install
npm run dev
```

| دستور | کار |
| --- | --- |
| `npm run dev` | اجرای برنامه در حالت توسعه |
| `npm run build` | ساخت نسخهٔ آمادهٔ اجرا |
| `npm run preview` | پیش‌نمایش همان نسخهٔ ساخته‌شده |

`npm install` یک‌بار ماژول پایگاه‌داده را برای Electron بازسازی می‌کند. اگر بعد از به‌روزرسانی وابستگی‌ها برنامه بالا نیامد، همان دستور را دوباره اجرا کنید.

## راهنمای کوتاه

1. یک استراتژی بسازید، یا همان فیلدهای پیش‌فرض را نگه دارید.
2. یک حساب بسازید: نام، موجودی اولیه، و در صورت نیاز درصد هدف. استراتژی‌های مربوط به آن حساب را انتخاب کنید.
3. از صفحهٔ حساب، معاملهٔ جدید را باز کنید، فیلدها را پر کنید و ذخیره کنید.
4. برای دیدن روند حساب، گزارش را باز کنید.
5. از جدول معاملات می‌توانید فیلتر کنید و خروجی CSV بگیرید.
6. از منوی کناری، پشتیبان را ذخیره کنید. برای برگرداندن، فایل `.skyjournal` را وارد کنید.

### ورود از پوشهٔ عکس

اگر چارت‌ها را در پوشه‌های جدا گذاشته‌اید، SkyJournal می‌تواند از نام پوشه معامله بسازد. نام هر پوشه یکی از این دو شکل است:

```text
+2
-1|buy
+3|sell
-1.5|خرید
```

عدد، اندازهٔ ریوارد است. علامت `+` یعنی سود، `-` یعنی ضرر، و صفر یعنی ریسک‌فری. بخش بعد از `|` نوع معامله است: `buy` / `sell` یا `خرید` / `فروش`. اگر این بخش نباشد، نوع معامله را در مرحلهٔ بعد خودتان انتخاب می‌کنید.

## داده‌ها کجا ذخیره می‌شوند؟

پایگاه‌داده و تصویر چارت‌ها در پوشهٔ دادهٔ برنامه روی همین دستگاه ذخیره می‌شوند. با بستن برنامه چیزی به سرور فرستاده نمی‌شود. برای جابه‌جایی به کامپیوتر دیگر، از پشتیبان `.skyjournal` استفاده کنید؛ این فایل هم معاملات را دارد و هم تصویرها را.

## فناوری‌ها

| بخش | ابزار |
| --- | --- |
| اپ دسکتاپ | Electron |
| رابط | React و TypeScript |
| ساخت | Vite و electron-vite |
| ظاهر | Tailwind CSS |
| ذخیرهٔ محلی | SQLite (`better-sqlite3`) |
| نمودار گزارش | Recharts |

رابط وب به Node.js وصل نیست. کار با فایل و پایگاه‌داده از فرایند اصلی Electron و یک پل محدود انجام می‌شود.

## ساختار پروژه

```text
electron/main      فرایند اصلی: پنجره، پایگاه‌داده، پشتیبان، خروجی و ورود عکس
electron/preload   پل امن بین رابط و فرایند اصلی
src/pages          صفحه‌های حساب، معامله، گزارش و ورود عکس
src/components     جدول، فرم‌ها، گفتگوها و پوسته
src/lib            نوع‌ها، محاسبهٔ سود و ضرر، فیلتر و خروجی
```
